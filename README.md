# 同音 TongYin

**安卓平板编曲 App** · 自用 · 免费 · 离线 · 无广告

当前版本：**v0.1 骨架版**
包名：`com.zhousirui.tongyin`

---

## 这一版能做什么

- 装到平板上，打开能看到主界面
- 8 个琴键，按下去会出声（C4 到 C5 一个八度）
- 声音由代码实时算出（基波 + 两个泛音 + 包络），**不是**采样音色，所以听起来偏电子
- 目的只有一个：验证这台平板能不能出声、延迟有多大、触屏手感如何

**这一版还没有**：音序器、钢琴卷帘、多轨、音色库、保存、导出。这些是后面每个版本一点点加上去的。

## 怎么拿到 APK（不用装任何开发软件）

整个过程在浏览器里完成，大约 15 分钟。

### 第 1 步：注册 GitHub 账号

打开 <https://github.com/signup>，用邮箱注册，免费。中文界面的话右上角可以切换语言。

### 第 2 步：新建一个仓库

1. 登录后点右上角的 **+** → **New repository**
2. **Repository name** 填 `tongyin`
3. 选 **Private**（私有，别人看不到）
4. 其他都不用动，点 **Create repository**

### 第 3 步：安装 GitHub Desktop，把文件传上去

浏览器里拖拽文件夹经常失败（特别是 `.github` 这种以点开头的隐藏文件夹，Windows 默认看不见它，容易漏掉）。用桌面客户端最稳。

1. 打开 <https://desktop.github.com/download/>，下载安装 GitHub Desktop（Windows 版，约 100MB，免费）
2. 打开后点 **Sign in to GitHub.com**，用刚注册的账号登录
3. 菜单 **File → Clone repository** → 切到 **GitHub.com** 标签 → 列表里找到 `zhousirui0714/tongyin` → **Local path** 随便选个记得住的位置 → 点 **Clone**
4. 打开 Windows 文件资源管理器，在顶部「**查看**」菜单里勾选「**隐藏的项目**」——这一步不能省，否则 `.github` 文件夹看不见、复制不全
5. 进入 `D:\07_\tongyin-app`，按 **Ctrl + A** 全选、**Ctrl + C** 复制
6. 进入第 3 步克隆下来的那个文件夹（里面有 `.git` 和 `README.md`），按 **Ctrl + V** 粘贴；提示「文件已存在」时选**替换**
7. 回到 GitHub Desktop，左侧面板会列出所有新增和修改的文件——**应该能看到 `.github/workflows/build-apk.yml`**，看不到就说明第 4 步没做对
8. 左下角 Summary 框里填 `v0.1 骨架版`，点 **Commit to main**
9. 点窗口顶部中间的 **Push origin**

推送完成后，仓库里就有全部文件了。

> 万一第 7 步找不到 `.github`：在 GitHub 网页上点 **Add file → Create new file**，文件名框里直接输入 `.github/workflows/build-apk.yml`（斜杠会自动变成目录），然后把本地同名文件的内容整段粘进去，提交即可。只补这一个文件就行，其余照常。

### 第 4 步：等它自动打包

1. 点仓库顶部的 **Actions** 标签
2. 左边会有一个 **Build APK**，点它
3. 会看到一条正在跑的记录（黄点）。大约 3–6 分钟，第一遍要下载依赖，可能久一点
4. 变成**绿色对勾**就成功了

### 第 5 步：下载 APK

构建成功后，APK 会被自动发布到 Releases 页面，这是最省事的下载方式：

1. 打开 <https://github.com/zhousirui0714/tongyin/releases>
2. 点最新的 **同音 · 最新构建**
3. 页面下方 **Assets** 里点 `tongyin.apk` 直接下载，不用解压

如果 Releases 页面暂时是空的，说明发布那一步还没跑完或者失败了，这时可以走备用路线：Actions → Build APK → 点进绿色的运行记录 → 拉到最底部 → **Artifacts** → `tongyin-apk`（这个下载下来是 zip，需要解压）。

> 平板浏览器下载和解压都不太顺手，建议在电脑上把 APK 下好再传到平板。

## 装到华为平板上

你这台是 **MatePad（BTK-W00）/ HarmonyOS 4.2**，能装 APK，但有两道系统限制要先关掉。

### 1. 退出「纯净模式」

设置 → 系统和更新 → **纯净模式** → 点 **退出**

不退出的话，安装时一定会提示「未通过华为安全检测」，而且没有「继续安装」的选项。

### 2. 允许文件管理器安装应用

设置 → 应用和服务 → 应用管理 → 右上角 ⋮ → **特殊访问权限** → **安装未知应用** → 找到你用来打开 APK 的程序（文件管理 / 微信），打开开关。

### 3. 把 APK 传到平板

任选一种：数据线拷到「下载」目录、微信「文件传输助手」发给自己、网盘。

### 4. 点开安装

用「文件管理」找到 APK 点开 → 安装。第一次会弹权限确认，允许即可。

装好后桌面上会出现「同音」图标。

### 5. 试一下

打开 App，按下任意一个琴键。应该能听到声音，底部会显示刚才按的是哪个音、多少赫兹。

## 出了问题怎么办

**Actions 里是红色叉号**
点进那次运行，点开红色那一步，把日志最后 20 行左右的内容发我。最常见的原因是某个文件没传上去，或者目录多套了一层。

**提示「未通过安全检测」**
纯净模式没退干净。回到设置里再看一遍，退出后建议重启一次平板。

**提示「解析软件包时出现问题」**
APK 下载不完整（浏览器断点续传失败）。重新下载一次，或者换个浏览器。

**装上但没声音**
先确认平板没静音、音量不是 0。如果还是没声音，把平板型号和现象告诉我——这正好是这一版要验证的东西。

**声音有延迟、听起来像电子琴**
属于预期内。这一版用的是最简单的 AudioTrack，正式版会换成 Oboe 低延迟通道 + 真实音色库。

## 工程里都有什么

```
tongyin-app/
├─ .github/workflows/build-apk.yml   云端自动打包脚本（GitHub 就是照这个干活的）
├─ app/
│  ├─ build.gradle.kts               应用配置：包名、版本号、依赖库
│  ├─ proguard-rules.pro             混淆规则（现在没用上，留空备用）
│  └─ src/main/
│     ├─ AndroidManifest.xml         应用的「身份证」：名字、图标、启动页面
│     ├─ java/com/zhousirui/tongyin/
│     │  ├─ MainActivity.kt          界面：标题、试听面板、8 个琴键
│     │  └─ ToneEngine.kt            发声：算波形、交给系统播放
│     └─ res/
│        ├─ drawable/ic_launcher.xml 桌面图标
│        └─ values/                  应用名、主题色
├─ build.gradle.kts                  项目级插件版本
├─ settings.gradle.kts               模块声明
└─ gradle.properties                 构建参数
```

## 技术备忘（以后改代码时要看）

版本是刻意锁定的，这一组组合已经验证能互相配合，**不要随手升级**：

- Gradle 8.7 / Android Gradle Plugin 8.5.2
- Kotlin 1.9.24 / Compose 编译器 1.5.14
- Compose BOM 2024.06.00
- compileSdk 34，minSdk 26（Android 8.0），targetSdk 34
- JDK 17

要升级的话，四者必须一起动：AGP、Gradle、Kotlin、Compose 编译器版本有严格对应关系，单独升一个必然报错。

另外提醒一句：这台平板是 **HarmonyOS 4.2**，能跑 APK。如果将来系统升级到 **HarmonyOS NEXT**，APK 就装不了了，届时需要改写成鸿蒙原生（ArkTS）。看到系统更新提示时先别急着点。
